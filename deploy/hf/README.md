# SolarTriage

Drona termică inspectează parcul fotovoltaic, un model ML (ansamblu de două ResNet18) găsește
modulele defecte și spune cât e de sigur, iar aplicația scrie ordinele de lucru și planul pe
echipe. FastAPI + React, într-un singur container.

Codul complet și instrucțiunile sunt în repo-ul proiectului (README.md).
